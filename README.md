## AI Resume Skill Recommendation System

## Project Overview

The AI Resume Skill Recommendation System is an NLP-based web application developed using Python and Streamlit. This project analyzes resumes, extracts technical skills using Natural Language Processing (NLP), compares them with industry-required skills, and provides personalized career recommendations.

The system helps users identify missing skills, improve resume quality, and explore learning resources for their target job roles.

---

## Features

*  Upload Resume in PDF Format
*  Automatic Skill Extraction using NLP
*  Job Role Based Skill Matching
*  Skill Match Percentage Analysis
*  Missing Skill Recommendations
*  Resume Feedback Suggestions
*  Skill Gap Visualization using Pie Charts
*  Career Roadmap Suggestions
*  Recommended Learning Resources

---

## Technologies Used

* Python
* Streamlit
* spaCy NLP
* PyMuPDF
* Matplotlib

## Installation

Install the required libraries:

```bash id="m4z3pt"
pip install streamlit pymupdf spacy matplotlib
```

Download the spaCy NLP model:

```bash id="mxh8lf"
python -m spacy download en_core_web_sm
```
